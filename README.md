# Recursos del CER Vijagual

Sitio de recursos y herramientas que acompañan las planeaciones del Centro Educativo Rural Vijagual (Carepa, Antioquia).
Las páginas se construyen con `python3 _plantilla/construir.py` a partir de los fragmentos de `_paginas/`, que reciben el encabezado institucional y el lema.
Aquí solo se publica material para estudiantes: nunca claves de pruebas ni datos personales.
